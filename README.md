# wcp-web

เว็บไซต์ของ World Class Plastic (HTML ล้วน deploy อัตโนมัติบน Vercel เมื่อ push เข้า `main`)

## ไฟล์ต้นฉบับ (Source files)

ไฟล์ต้นฉบับทั้งหมดเก็บอยู่นอก repo ที่โฟลเดอร์นี้ **ให้อ่านไฟล์ต้นฉบับจากที่นี่ก่อนเริ่มงานทุกครั้ง**

```
C:\projects\inbox\
├── doc\       เอกสาร ข้อมูลบริษัท รายละเอียดสินค้า ข้อความที่จะใช้บนเว็บ
└── picture\   รูปภาพต้นฉบับ เช่น โลโก้ รูปสินค้า รูปโรงงาน
```

- ข้อความบนเว็บ (ที่อยู่ เบอร์โทร LINE รายชื่อสินค้า ฯลฯ) ให้ใช้ข้อมูลจาก `doc\`
- รูปที่ใช้บนเว็บ ครอปมาจาก `picture\` ด้วยสคริปต์ `tools/crop-images.ps1` (ดูด้านล่าง)
- อย่าแก้ไขหรือลบไฟล์ใน `inbox` ให้ถือเป็นต้นฉบับ

## โครงสร้างโปรเจกต์

```
wcp-web/
├── index.html              หน้าเว็บ (ต้องอยู่ที่ root เพื่อให้ Vercel เสิร์ฟ)
├── assets/
│   ├── css/style.css       สไตล์ทั้งหมด
│   ├── js/main.js          เมนูมือถือ สไลด์แบนเนอร์ แท็บสินค้า
│   └── images/
│       ├── brand/          โลโก้
│       ├── factory/        รูปโรงงาน เครื่องจักร เม็ดพลาสติก
│       ├── products/       รูปสินค้าแต่ละชนิด และกราฟิกสินค้าขายดี
│       ├── oem/            ตัวอย่างงาน OEM และฉลาก
│       └── gallery/        รูปกิจกรรมและสินค้าแพ็คพร้อมส่ง
├── tools/
│   └── crop-images.ps1     สคริปต์ครอปรูปจาก inbox ไปไว้ใน assets/images
├── README.md
└── CLAUDE.md               กฎและข้อห้ามของโปรเจกต์
```

## รูปภาพ

รูปทั้งหมดใน `assets/images/` ถูกครอปจากสไลด์ใน `C:\projects\inbox\picture\` ถ้าต้นฉบับเปลี่ยน ให้รันใหม่:

```powershell
powershell -ExecutionPolicy Bypass -File tools\crop-images.ps1
```

| โฟลเดอร์ | ครอปจาก | ใช้ที่ |
|---|---|---|
| `brand/` | `logo.jpg` | โลโก้ header / footer |
| `factory/` | `1.png`, `3.png`, `8.png` | แบนเนอร์, เกี่ยวกับเรา, จุดแข็ง, ทดสอบคุณภาพ |
| `products/` | `4.png`, `5.png`, `6.png`, `menu.png` | การ์ดสินค้า, หมวดสินค้าขายดี |
| `oem/` | `7.png`, `10.png` | ขนาดมาตรฐาน, แพ็กเกจ OEM |
| `gallery/` | `2.png`, `9.png` | เกี่ยวกับเรา, ลูกค้าของเรา |
