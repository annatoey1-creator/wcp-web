# World Class Plastic (WCP) - เว็บไซต์บริษัท

เว็บไซต์อย่างเป็นทางการของ **บริษัท เวิลด์คลาสพลาสติก จำกัด (World Class Plastic Co., Ltd.)**  
โรงงานผู้เชี่ยวชาญด้านการผลิตและจัดจำหน่ายถุงพลาสติก HDPE ถุงขยะดำ ถุงขยะสี และบริการรับผลิต OEM ครบวงจร ประสบการณ์มากกว่า 20 ปี

🔗 **Live Website:** [https://wcp-web.vercel.app](https://wcp-web.vercel.app)

## ภาพรวมโปรเจกต์

เว็บไซต์นี้พัฒนาด้วย **HTML, CSS และ JavaScript ล้วน (Pure / Vanilla Web)** โดยไม่มี build tools หรือ framework เพิ่มเติม เพื่อความเรียบง่าย รวดเร็วในการโหลด และง่ายต่อการปรับแต่ง ออกแบบให้รองรับการแสดงผลแบบ Responsive เต็มรูปแบบทั้งบนเดสก์ท็อป แท็บเล็ต และสมาร์ทโฟน

### ข้อมูลสำคัญของบริษัท (จากสไลด์นำเสนอ)
- **ประสบการณ์:** มากกว่า 20 ปีในอุตสาหกรรมพลาสติกรีไซเคิล
- **ยอดขายและการผลิต:** มากกว่า 200 ตันต่อเดือน
- **กำลังการผลิต:** มากกว่า 3 ตันต่อวัน
- **ขั้นต่ำการผลิต (MOQ):** เริ่มต้นเพียง 300 กก.
- **จุดเด่น:** มีโรงงานผลิตเม็ดพลาสติกเอง ควบคุมความเหนียว ความหนา (>0.12 มม.) และคุณภาพเกรดส่งออก

## ฟีเจอร์และโครงสร้างหน้าเว็บ

หน้าเว็บหลัก (`index.html`) ประกอบด้วยส่วนต่าง ๆ ดังนี้:

1. **Top Bar & Navigation Header:**
   - สโลแกน *"To be one of the best Thai plastic recycle"*
   - ลิงก์ด่วน: Facebook, เบอร์โทรศัพท์ติดต่อ (`061-968-2828`)
   - เมนูหลักพร้อมระบบ Smooth Scroll ไปยังแต่ละส่วน
   - เมนูมือถือแบบ Responsive (แฮมเบอร์เกอร์เมนู)
2. **Hero Banner Slider:**
   - สไลด์ภาพโรงงานและกระบวนการผลิต เปลี่ยนภาพอัตโนมัติทุก 5 วินาที
   - ปุ่ม Call-to-Action โทรสอบถาม และปุ่มเลื่อนดูสินค้า
3. **เกี่ยวกับเรา (About Us):**
   - ประวัติ ความเป็นมา วิสัยทัศน์ และตัวเลขสถิติความสำเร็จ
   - แกลเลอรีภาพแพ็กเกจสินค้าพร้อมส่ง
4. **จุดแข็งของเรา (Strengths):**
   - 6 จุดเด่นหลัก: รับทำ OEM ครบวงจร, บริการจัดส่งทั่วไทย/เพื่อนบ้าน, มาตรฐาน QC, ผลิตรวดเร็ว, ควบคุมวัตถุดิบเอง, คุณภาพเหนียวทนทาน
5. **สินค้าของเรา (Products):**
   - แท็บสลับกลุ่มสินค้า (Interactive Tabs):
     - **ถุงขยะสีและงานพิเศษ:** ขาวขุ่น, แดง (ขยะติดเชื้อ), เหลือง (รีไซเคิล), เขียว (ขยะอินทรีย์), น้ำเงิน, ดำ, แดงพิมพ์ชื่อโรงพยาบาล, ม้วน HDPE ห่อเฟอร์นิเจอร์, ถุงใส่น้ำยาง PE, ถุงรองกล่องปลูกผัก
     - **ถุงขยะดำ / หูหิ้วดำ:** ถุงหูหิ้วดำบาง A, ถุงขยะดำบาง A, ถุงหูหิ้วดำหนา B พร้อมขนาดและจำนวนใบ
     - **ถุงหูหิ้ว / ถุงร้อน-เย็น:** ถุงหูหิ้วงา (บาง/หนา), ถุงเย็นมงกุฎ, ถุงร้อนมงกุฎ PP หลากหลายขนาด
   - **Best Seller Showcase:** หมวดหมู่สินค้าขายดี พร้อมกราฟิกประกอบ
6. **ทดสอบคุณภาพ (Quality Test):**
   - รายละเอียดการตรวจสอบความหนาด้วยเครื่องวัด (0.12 มม.) และเกณฑ์การควบคุมคุณภาพ
7. **ขนาดมาตรฐาน & MOQ (Standard Sizing):**
   - ตารางแจกแจงขนาดมาตรฐาน 10 ขนาด (18×20 ถึง 40×60 นิ้ว), จำนวนใบต่อ กก., ความหนา, ขนาดพับข้าง
   - เงื่อนไขขั้นต่ำการสั่งผลิต (MOQ 300 กก.)
8. **แพ็กเกจรับทำ OEM (Pricing for OEM):**
   - การ์ดราคา 4 แพ็กเกจ: **BASIC** (9,600 บาท), **STANDARD** (74,700 บาท), **PREMIUM** (84,700 บาท), **PROFESSIONAL** (153,500 บาท)
9. **ความไว้วางใจและช่องทางจำหน่าย (Market Presence):**
   - ภาพกิจกรรม ภาพการทดสอบความแข็งแรงของถุง และช่องทางออนไลน์ (Facebook, Shopee, TikTok)
10. **ติดต่อเรา & ฟอร์มสอบถาม (Contact Us):**
    - ข้อมูลติดต่อ เบอร์โทร ช่องทางโซเชียล
    - ฟอร์มกรอกข้อความสอบถามราคา (จำลอง Mockup)
    - พื้นที่สำหรับฝัง Google Maps
11. **Footer:**
    - ข้อมูลสรุปบริษัท ลิงก์เมนูด่วน และลิขสิทธิ์ประจำปี (คำนวณปีอัตโนมัติด้วย JS)

## เทคโนโลยีที่ใช้

- **HTML5:** Semantic markup รองรับ SEO และ Accessibility
- **CSS3:** Custom stylesheet (`assets/css/style.css`)
  - CSS Variables สำหรับจัดการธีมสี (เขียวเข้ม, เขียวสด, ทอง, พื้นหลัง)
  - Responsive Flexbox & Grid layouts
  - Backdrop blur filter สำหรับ sticky header
  - Fluid typography และ Smooth scrolling
- **Vanilla JavaScript:** สคริปต์ทำงานฝั่งเบราว์เซอร์ (`assets/js/main.js`)
  - Mobile Navigation Drawer Toggle
  - Hero Carousel Slider พร้อมระบบ Auto-play และ Indicator Dots
  - Tab Filtering แสดง/ซ่อนสินค้าตามหมวดหมู่
  - อัปเดตปี ค.ศ. ลิขสิทธิ์อัตโนมัติ
- **Web Fonts:** Google Fonts
  - `Prompt` (สำหรับหัวข้อ / Headings / ตัวเลข)
  - `Sarabun` (สำหรับเนื้อหาทั่วไป / Body text)

## การรันและดูตัวอย่างในเครื่อง (Local Preview)

เนื่องจากเป็นโปรเจกต์ Static HTML ล้วน จึงสามารถเปิดดูได้ทันทีโดยไม่ต้องติดตั้ง runtime หรือ build tools ใด ๆ:

### วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์
ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดผ่านเบราว์เซอร์ได้ทันที

### วิธีที่ 2: ใช้ Local HTTP Server (แนะนำ)
หากต้องการทดสอบผ่าน Local HTTP Server:

```powershell
# ผ่าน Node.js (npx serve)
npx serve .

# หรือผ่าน Python
python -m http.server 8080

# หรือผ่าน PHP
php -S localhost:8080
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`

## ไฟล์ต้นฉบับและการจัดการรูปภาพ

### แหล่งไฟล์ต้นฉบับ (Inbox)
ไฟล์เอกสารและภาพถ่ายต้นฉบับเก็บอยู่นอก repository ที่:
```
C:\projects\inbox\
├── doc\       # เอกสาร ข้อมูลบริษัท รายละเอียดสินค้า (ใช้เป็นข้อเท็จจริง ห้ามแต่งเพิ่ม)
└── picture\   # สไลด์และภาพต้นฉบับความละเอียดสูง (1.png - 11.png, logo.jpg, menu.png)
```

> [!IMPORTANT]
> **ข้อห้ามสำคัญ:** ห้ามแก้ไข ลบ หรือย้ายไฟล์ใน `C:\projects\inbox\` โดยเด็ดขาด ให้อ่านอย่างเดียว

### การครอปและประมวลผลรูปภาพ
รูปภาพในโฟลเดอร์ `assets/images/` ทั้งหมดถูกสกัดและครอปจากสไลด์ใน `inbox/picture` อัตโนมัติผ่าน PowerShell สคริปต์:

```powershell
powershell -ExecutionPolicy Bypass -File tools\crop-images.ps1
```

#### ตารางการแมปรูปภาพต้นฉบับ:

| โฟลเดอร์ปลายทาง | ไฟล์ต้นฉบับ | ตำแหน่งที่ใช้บนเว็บไซต์ |
|---|---|---|
| `brand/` | `logo.jpg` | โลโก้ใน Header, Footer และ Favicon |
| `factory/` | `1.png`, `3.png`, `8.png` | Hero banner, ส่วนเกี่ยวกับเรา, จุดแข็ง, การทดสอบความหนา |
| `products/` | `4.png`, `5.png`, `6.png`, `menu.png` | การ์ดรายการสินค้าแยกหมวดหมู่, หมวด Best Seller |
| `oem/` | `7.png`, `10.png` | ภาพตัวอย่างฉลากสินค้า, การ์ดแพ็กเกจ OEM 4 ระดับ |
| `gallery/` | `2.png`, `9.png` | ภาพสินค้าแพ็คพร้อมส่ง, ภาพกิจกรรมและรีวิวการใช้งาน |

โปรเจกต์นี้ตั้งค่าเชื่อมต่อกับ **Vercel** ไว้อย่างสมบูรณ์:

## รายการข้อมูล Mockup ที่รอข้อมูลจริง

ใน `index.html` มีบางจุดที่เป็นข้อมูลตัวอย่าง (จะแสดงแถบแจ้งเตือนสีเหลืองด้านล่างของหน้าเว็บ) ซึ่งรอข้อมูลยืนยันจากบริษัท:

1. **ที่อยู่สำนักงาน / โรงงาน:** ปัจจุบันใส่เป็น `[ที่อยู่บริษัท]`
2. **LINE Official ID:** ปัจจุบันใส่เป็น `[LINE ID]`
3. **อีเมลติดต่อ:** ปัจจุบันใส่เป็น `[อีเมล]`
4. **Google Maps:** รอพิกัดจริงเพื่อนำ iframe embed มาใส่แทนกล่อง mockup
5. **ระบบส่งแบบฟอร์มติดต่อ:** ปัจจุบันเป็น mockup แสดง JavaScript alert จำเป็นต้องเชื่อมต่อ Form backend (เช่น Formspree, Resend หรือ API) เมื่อพร้อมใช้งาน

## กฎและข้อตกลงในการพัฒนา (Guidelines)

เพื่อรักษาความถูกต้องและมาตรฐานของโปรเจกต์ ให้ปฏิบัติตามกฎใน `CLAUDE.md`:

1. **ห้ามแต่งข้อมูลธุรกิจขึ้นเอง:** ข้อมูลที่อยู่ เบอร์โทร สถิติการผลิต และมาตรฐาน ต้องอ้างอิงจากเอกสารใน `inbox` เท่านั้น หากยังไม่มีให้ใส่เป็น `[placeholder]`
2. **ห้ามนำเข้า Framework หรือ Build Tool:** คงความเป็น HTML/CSS/JS ล้วน ไม่เพิ่ม React, Tailwind, Vite, Webpack หรือ dependencies ใน `package.json` เว้นแต่จะได้รับความเห็นชอบ
3. **ห้าม Push ขึ้น `main` โดยไม่ได้รับอนุญาต:** เนื่องจาก branch `main` เชื่อมต่อกับ Production บน Vercel โดยตรง
4. **ไฟล์ต้นฉบับเป็น Read-only:** ทำงานกับสำเนาใน `wcp-web/` เท่านั้น ห้ามแตะต้องโฟลเดอร์ `inbox`
